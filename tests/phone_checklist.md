# 5-minute real-phone check (Android Chrome)

Open the site, then tick each line. Send me a screenshot or one line for anything that fails.

1. Install: menu → "Add to Home screen". It opens full-screen from the icon with no browser bar.
2. Run: tap Run on the default program. Output appears, and the keyboard does not cover the Run button.
3. Typing: tap the editor, type a line, use the `{ } ( ) ;` key row. Cursor stays visible above the keyboard.
4. Format: tap the lines icon next to +. Code re-indents, and the toast appears.
5. ⋯ menu: opens inside the screen, every item is tappable, Hinglish switch changes the explanations.
6. Error: delete a `;`, Run. A plain explanation shows (try Hinglish too).
7. Input: run a `scanf` example. The input box appears and the program continues after Enter.
8. Debug: tap the bug icon, step a few times, open the memory picture. Nothing is clipped.
9. Score: tap the check icon. A score, the fix examples and the Send result button show.
10. Offline: turn on airplane mode, close and reopen the app from the icon. It still runs code.
11. Update: after I push, open the app twice. The new version appears without clearing data.
12. Rotate to landscape: nothing overlaps.
